# AhaSend Documentation

Source for the [AhaSend documentation](https://ahasend.com/docs). AhaSend is a transactional email service built for developers.

The docs cover the REST API, SMTP relay, CLI, webhooks, domain setup, security features, and integration guides.

## Support

Found a problem in the docs? Open an issue or pull request in this repository. For help with your AhaSend account, email support@ahasend.com.
