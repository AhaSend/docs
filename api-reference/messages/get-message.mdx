---
title: "Get a Message by ID via the API"
sidebarTitle: "Get Message"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/messages/{message_id}"
description: "Retrieve a single email sent through AhaSend by message ID, including its delivery status and the raw email content when your retention settings keep it."
---

Returns the complete message by its ID, including raw content and parsed content structure.
Access requires `messages:read:all` or a read role matching the
message's sender domain.

Returns a message by its ID.

The main difference between the response of this API and the response of the
[List Messages API](/api-reference/messages/get-messages) is that this API returns
a single message including the original, raw email `content` (if available),
while the message objects returned in the List Messages API do not include
the email `content`.
Message `content` and `content_parsed` are absent when message-data retention has expired or was set to 0. See [retention](/retention).
