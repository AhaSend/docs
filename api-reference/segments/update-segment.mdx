description: "Change the name, description, rules or time zone of an AhaSend segment. New rules or a new time zone make AhaSend find the members of the segment again."
---


The AhaSend API changes one segment. Access requires `segments:write`.

**Fields:**
- A field that you leave out or send as `null` does not change.
- `name` and `description` follow the same rules as in [Create Segment](/api-reference/segments/create-segment).
- `definition` replaces the stored rules as a whole. See [Definitions](/api-reference/segments/overview#definitions).
- `timezone` is an IANA time zone. An empty string stores `UTC`.
- A field that you cannot write is refused with `400`, and the message names it.

**Members:**
- A change of `definition` or `timezone` builds the members again. The segment is `building` until that ends, and a campaign that uses it cannot be sent until then.
- A change of only `name` or `description` keeps the members and the state.
- Any update of a `failed` segment, `{}` included, builds it again.

See [States](/api-reference/segments/overview#states).

A segment that is being changed, for example by an update of its members, answers `409` with `The segment is being updated. Try again in a minute.` Nothing was changed, so send the request again later.
