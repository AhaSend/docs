---
title: "Get a Campaign Template via the API"
sidebarTitle: "Get Template"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/campaign-templates/{template_id}"
description: "Retrieve an AhaSend campaign template by ID with its editor and content: the MJML or HTML design, AhaML for a Simple Editor design, and the plain text."
---


The AhaSend API returns a campaign template with its content. Access requires `templates:read`.

`content` is `null` when the campaign template has no HTML and no text, for example after a create without content. A campaign can copy the campaign template only when it has HTML.

The ID of a transactional template answers `404`. To read a transactional template, use [Get Template](/api-reference/templates/get-template).
