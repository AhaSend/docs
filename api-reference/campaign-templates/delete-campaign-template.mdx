sidebarTitle: "Delete Campaign Template"
openapi: "/openapi.yaml DELETE /v2/accounts/{account_id}/campaign-templates/{template_id}"
description: "Delete a campaign template from your AhaSend account. Campaigns made from it keep their own designs, and a second delete of the same ID returns 404."
---


The AhaSend API deletes a campaign template. Access requires `templates:delete`.

Campaigns made from the campaign template keep their own copies of the design. A second delete of the same campaign template answers `404`.
