The AhaSend API creates a new domain.

<Warning>The `dkim_private_key` parameter is currently only supported for <a href="https://ahasend.com/partners">Platform Partner</a> accounts.</Warning>
Bring-your-own DKIM uses RSA keys: 1024 bits minimum, 2048 bits recommended. See [Platform Partner features](/facts).
