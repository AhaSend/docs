description: "Change an AhaSend API key's label, scopes, or IP allow list. Returns 409 if a key would lock itself out by excluding the caller's current IP."
---

Updates an existing API key's label and scopes

You can update `label`, `scopes`, and `ip_allow_list`. See [IP allow lists](/security/ip-allow-lists).

Updating the key you are using returns `409` if its new IP allow list would exclude your current IP.
