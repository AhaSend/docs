---
title: "Get a Webhook via the API"
sidebarTitle: "Get Webhook"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/webhooks/{webhook_id}"
description: "Retrieve a single AhaSend webhook by ID with the API, including its URL, subscribed event types, enabled status and domain scope."
---

Returns a specific webhook by ID. Access requires the global read role
or a read role matching at least one associated domain.
