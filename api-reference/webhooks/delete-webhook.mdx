title: "Delete a Webhook via the API"
sidebarTitle: "Delete Webhook"
openapi: "/openapi.yaml DELETE /v2/accounts/{account_id}/webhooks/{webhook_id}"
description: "Delete an AhaSend webhook with the API to stop event deliveries to its endpoint. Requires a delete role for the webhook's domains or the global role."
---


The AhaSend API deletes a webhook. Access requires the global delete role or a delete
role matching at least one associated domain.
