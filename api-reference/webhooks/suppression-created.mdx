AhaSend sends this event when a suppression is created for an email address.

**Why suppressions are created**:
- Multiple hard bounces from the same email address
- Repeated soft bounces over time
- Manual suppression through the API or dashboard

**Auto-expiration**: Suppression duration depends on the cause: most bounces last 30 days, temporary delivery failures 7 days, messages that expire after repeated attempts 15 days, and spam complaints are effectively permanent. Suppressions created through the API use the required `expires_at` value.

**Impact**: Future emails to this address will be automatically suppressed until the suppression expires or is manually removed.

**When it's sent**: When a new suppression is added to your account.

Suppression duration depends on its cause, rather than a single fixed expiry. See [suppression durations](/api-reference/webhooks#suppression-duration).
