AhaSend webhook events report email delivery, engagement, suppression and domain changes; this reference lists every event and its payload. Use the [webhook setup guide](/integrations/webhooks) to configure an endpoint.

Available on Free, Pro and Max. See [plans and features](/facts#plans-and-features).

## Event Types

| Event type | Filter flag | Fires when | Payload |
|---|---|---|---|
| `message.reception` | `on_reception` | A message is accepted | [Reference](/api-reference/webhooks/message-reception) |
| `message.delivered` | `on_delivered` | The recipient server accepts the message | [Reference](/api-reference/webhooks/message-delivered) |
| `message.transient_error` | `on_transient_error` | A delivery attempt has a temporary failure | [Reference](/api-reference/webhooks/message-transient_error) |
| `message.failed` | `on_failed` | Message delivery fails | [Reference](/api-reference/webhooks/message-failed) |
| `message.bounced` | `on_bounced` | The recipient server rejects the message | [Reference](/api-reference/webhooks/message-bounced) |
| `message.suppressed` | `on_suppressed` | A suppression prevents sending | [Reference](/api-reference/webhooks/message-suppressed) |
| `message.opened` | `on_opened` | The tracking image is requested | [Reference](/api-reference/webhooks/message-opened) |
| `message.clicked` | `on_clicked` | A tracked link is requested | [Reference](/api-reference/webhooks/message-clicked) |
| `suppression.created` | `on_suppression_created` | A suppression is created | [Reference](/api-reference/webhooks/suppression-created) |
| `domain.dns_error` | `on_dns_error` | A sending domain has a DNS error | [Reference](/api-reference/webhooks/domain-dns_error) |

Inbound routing has a separate [`message.routing` event](/api-reference/routes/route-message).

## Suppression Duration

| Cause | Duration |
|---|---|
| Most bounces | 30 days |
| Temporary delivery failures | 7 days |
| Message expires after repeated attempts | 15 days |
| Spam complaint | Effectively permanent |
| Created through the API | Caller supplies the required `expires_at` |

## Payload Structure

All webhook events use a consistent JSON structure:

Events contain `type`, `webhook_id`, `timestamp`, and an event-specific `data` object. The payload `webhook_id` identifies the configured endpoint; the `webhook-id` header identifies the delivery across retries. Inbound routes use `route_id` instead of `webhook_id`. Use the payload reference for each event above.
