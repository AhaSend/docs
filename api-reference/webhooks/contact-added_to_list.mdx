---


AhaSend sends this event when a contact is added to a list, with any subscription status.

`data.list` is the list. `data.list_contact` is the new membership, and its `subscription_status` is the status that the contact got on the list. A new membership sends only this event, whatever its status.

**No event**: A CSV import to a list, and saving a contact search as a list.

**Setting**: `on_contact_added_to_list` (Contact Added to List in the dashboard).

**Requirements**:
- Your account has the marketing features. Contact events cannot be turned on without them.
- A webhook with this event on needs an API key with `contacts:read` and `lists:read` when you create or update it through the API. See [contact events](/api-reference/webhooks#contact-events).

**When it's sent**: When a contact is added to a list.
