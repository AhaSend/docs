---
title: "List SMTP Credentials via the API"
sidebarTitle: "List SMTP Credentials"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/smtp-credentials"
description: "List all SMTP credentials in your AhaSend account through the API, with their scope and sending domains, using cursor-based pagination."
---

Returns a list of SMTP credentials for the account. The global read role
sees all credentials; domain-scoped roles return credentials associated
with at least one authorized domain.
