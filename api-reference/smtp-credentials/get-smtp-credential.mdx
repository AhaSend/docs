---
title: "Get an SMTP Credential via the API"
sidebarTitle: "Get SMTP Credential"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/smtp-credentials/{smtp_credential_id}"
description: "Retrieve one AhaSend SMTP credential by ID through the API, including its username, scope and associated sending domains."
---

Returns a specific SMTP credential by ID. Access requires the global
read role or a read role matching at least one associated domain.
