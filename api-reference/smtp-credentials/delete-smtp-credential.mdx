---
title: "Delete an SMTP Credential via the API"
sidebarTitle: "Delete SMTP Credential"
openapi: "/openapi.yaml DELETE /v2/accounts/{account_id}/smtp-credentials/{smtp_credential_id}"
description: "Revoke an AhaSend SMTP credential by ID through the API. Revoke credentials when you rotate secrets or after a password leaks."
---

Deletes an SMTP credential. Access requires the global delete role or a
delete role matching at least one associated domain.
