title: "Resume a Sub-Account via the API"
sidebarTitle: "Resume Sub-Account"
openapi: "/openapi.yaml POST /v2/accounts/{account_id}/sub-accounts/{sub_account_id}/unsuspend"
description: "Resume sending on a paused AhaSend sub-account from the parent account so its status returns to active. Requires the sub-accounts:suspend scope."
---


The AhaSend API resumes sending on a paused sub-account under the parent account.

<Info>
  **Plan availability:** sub-accounts are included on Pro (up to 9) and Max (no limit). There is no charge per sub-account; the volume of all sub-accounts is pooled on the parent's plan. See [plans and features](/facts#plans-and-features).
</Info>
