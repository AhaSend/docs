title: "Update a Sub-Account API Key via the API"
sidebarTitle: "Update API Key"
openapi: "/openapi.yaml PUT /v2/accounts/{account_id}/sub-accounts/{sub_account_id}/api-keys/{key_id}"
description: "Change the label, scopes, or IP allow list of an API key owned by an AhaSend sub-account. Scopes are validated against the child account."
---

Updates the label and scopes for an API key owned by a sub-account. Updated scopes are validated against the child account.

<Info>
  **Platform Partner feature:** Sub-Accounts is part of our Platform Partner capabilities and is currently in early access. [Contact us](https://ahasend.com/contact) to enable it on your account.
</Info>

You can update `label`, `scopes`, and `ip_allow_list`. See [IP allow lists](/security/ip-allow-lists).
