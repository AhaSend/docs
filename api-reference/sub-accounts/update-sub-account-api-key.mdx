openapi: "/openapi.yaml PUT /v2/accounts/{account_id}/sub-accounts/{sub_account_id}/api-keys/{key_id}"
description: "Change the label, scopes, or IP allow list of an API key owned by an AhaSend sub-account. Scopes are validated against the child account."
---


The AhaSend API updates the label and scopes for an API key owned by a sub-account. Updated scopes are validated against the child account.

<Info>
  **Plan availability:** sub-accounts are included on Pro (up to 9) and Max (no limit). There is no charge per sub-account; the volume of all sub-accounts is pooled on the parent's plan. See [plans and features](/facts#plans-and-features).
</Info>

You can update `label`, `scopes`, and `ip_allow_list`. See [IP allow lists](/security/ip-allow-lists).
