title: "Get Sub-Account Usage via the API"
sidebarTitle: "Sub-Account Usage"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/sub-accounts/usage"
description: "Get AhaSend message volume and proportionally allocated cost for the parent and each sub-account in the current billing period, for customer rebilling."
---


The AhaSend API returns current billing-period usage and proportional allocated cost for the parent and active sub-accounts.

<Info>
  **Plan availability:** sub-accounts are included on Pro (up to 9) and Max (no limit). There is no charge per sub-account; the volume of all sub-accounts is pooled on the parent's plan. See [plans and features](/facts#plans-and-features).
</Info>

<Note>
`allocated_cost` is a proportional share of the parent account's pooled invoice, not standalone pricing.
</Note>
