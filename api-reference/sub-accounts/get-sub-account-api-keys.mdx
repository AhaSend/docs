---
title: "List Sub-Account API Keys via the API"
sidebarTitle: "List API Keys"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/sub-accounts/{sub_account_id}/api-keys"
description: "List all API keys owned by an AhaSend sub-account with cursor pagination, using parent credentials. Secret keys are omitted from list responses."
---


The AhaSend API returns a cursor-paginated list of API keys owned by a sub-account. The `secret_key` field is omitted from list responses.

<Info>
  **Plan availability:** sub-accounts are included on Pro (up to 9) and Max (no limit). There is no charge per sub-account; the volume of all sub-accounts is pooled on the parent's plan. See [plans and features](/facts#plans-and-features).
</Info>
