---
title: "List Sub-Account API Keys via the API"
sidebarTitle: "List API Keys"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/sub-accounts/{sub_account_id}/api-keys"
description: "List all API keys owned by an AhaSend sub-account with cursor pagination, using parent credentials. Secret keys are omitted from list responses."
---

Returns a cursor-paginated list of API keys owned by a sub-account. The `secret_key` field is omitted from list responses.

<Info>
  **Platform Partner feature:** Sub-Accounts is part of our Platform Partner capabilities and is currently in early access. [Contact us](https://ahasend.com/contact) to enable it on your account.
</Info>
