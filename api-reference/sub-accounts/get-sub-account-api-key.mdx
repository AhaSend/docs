---
title: "Get a Sub-Account API Key via the API"
sidebarTitle: "Get API Key"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/sub-accounts/{sub_account_id}/api-keys/{key_id}"
description: "Retrieve one API key owned by an AhaSend sub-account, including its label, scopes, and IP allow list. The secret_key is never returned after creation."
---


The AhaSend API returns a specific API key owned by a sub-account. The `secret_key` field is omitted from read responses.

<Info>
  **Plan availability:** sub-accounts are included on Pro (up to 9) and Max (no limit). There is no charge per sub-account; the volume of all sub-accounts is pooled on the parent's plan. See [plans and features](/facts#plans-and-features).
</Info>
