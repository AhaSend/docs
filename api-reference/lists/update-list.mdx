description: "Change the name, description or tags of an AhaSend contact list. Only the fields you send change, and a tags array replaces all stored tags."
---


The AhaSend API changes one list. Access requires `lists:write`.

**Fields:**
- A field that you leave out or send as `null` does not change.
- `tags` replaces all stored tags. An empty array removes them.
- `name`, `description` and `tags` follow the same rules as in [Create List](/api-reference/lists/create-list). A field that you cannot write is refused with `400`, and the message names it.
- A stored value that is outside these rules still reads back as it is. The API refuses it only when you send it back in an update.
