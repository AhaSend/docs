description: "Update an AhaSend inbound email route: change its webhook URL or recipient pattern, toggle attachments, headers or reply stripping, or re-enable it."
---


The AhaSend API updates an existing route. A domain-scoped key must authorize the
existing recipient domain and, when `recipient` changes, the new domain;
`routes:write:all` satisfies both checks.
