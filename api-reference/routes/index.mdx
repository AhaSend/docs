The AhaSend Routes API lets you create, list, update and delete inbound email routes; this page links the endpoints and the received-message payload. Follow the [routing guide](/integrations/routing) for MX setup, matching rules and dashboard configuration.

Available on Free, Pro and Max. See [plans and features](/facts#plans-and-features).

## API Operations

| Task | Endpoint reference |

| Read one route | [Get Route](/api-reference/routes/get-route) |

## Payload Structure

All routing events use a consistent JSON structure:

```json
{
  "type": "message.routing",
  "route_id": "11111111-1111-4111-8111-111111111111",
  "timestamp": "<RFC3339 delivery timestamp>",
  "data": {
    "from": "sender@example.com",
    "to": "support@yourdomain.com",
    "subject": "Email subject",
    "html_body": "<p>Email content</p>",
    "plain_body": "Email content"
  }
}
```

This is a shortened payload. See [the full routing schema](/api-reference/routes/route-message) for attachments, headers and reply fields.
