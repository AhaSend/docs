AhaSend signs inbound route deliveries using the Standard Webhooks headers and format. The route secret starts with `aha-rsec-`; use the literal UTF-8 bytes of the full secret, prefix included, as the HMAC-SHA256 key. Never base64-decode it.

The signed input is `webhook-id + "." + webhook-timestamp + "." + raw_body`. Verify the exact bytes before JSON parsing. Accept a matching `v1,<base64 signature>` entry from the space-separated signature header and reject timestamps more than five minutes from your clock.

Use the [runnable verification examples](/api-reference/webhooks/security#runnable-verification-examples) with your route secret. JavaScript Standard Webhooks needs `{ format: "raw" }`; Go needs `NewWebhookRaw`; Python needs a bytes secret. The AhaSend SDKs already use raw keys.

Deduplicate verified `webhook-id` values atomically with durable work. Return 2xx for verified unknown event types and already-processed deliveries. See [route retries](/api-reference/routes/retry-policy).
