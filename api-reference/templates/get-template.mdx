title: "Get a Transactional Template via the API"
sidebarTitle: "Get Template"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/templates/{template_id}"
description: "Retrieve an AhaSend transactional template by ID as its working copy: the draft while one exists, with its content, sender and variables."
---


The AhaSend API returns the working copy of a template: its draft while it has one, and its published copy otherwise. `has_draft` says which. Access requires `templates:read`.

[Update Template](/api-reference/templates/update-template) changes this copy, so you can read a template, change it and send it back. While a draft exists, `updated_at` here can differ from the one [List Templates](/api-reference/templates/get-templates) shows, because the list shows the published copy.

Sends use the published copy. To build a send, read [Get Published Template](/api-reference/templates/get-published-template): its `variables` are the ones each recipient must give.

Campaign templates have their own endpoints, and the ID of a campaign template answers `404` here. To read one, use [Get Campaign Template](/api-reference/campaign-templates/get-campaign-template).
