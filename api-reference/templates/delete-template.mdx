title: "Delete a Transactional Template via the API"
sidebarTitle: "Delete Template"
openapi: "/openapi.yaml DELETE /v2/accounts/{account_id}/templates/{template_id}"
description: "Delete a transactional template from your AhaSend account. Sends that use the template fail after it is deleted, and a second delete returns 404."
---


The AhaSend API deletes a transactional template. Access requires `templates:delete`.

After the delete, [Create Template Message](/api-reference/messages/create-template-message) refuses the template with `404`.
