---
title: "List Campaigns via the API"
sidebarTitle: "List Campaigns"
openapi: "/openapi.yaml GET /v2/accounts/{account_id}/campaigns"
description: "List the marketing campaigns in your AhaSend account, newest first, with their status, subject, sender and send times. Filter the list by status."
---


The AhaSend API returns the account's marketing campaigns, newest first. Access requires `campaigns:read`.

Use `status` to list only the campaigns in one status. Each campaign is listed without its audience, its design and its issues. To read them, use [Get Campaign](/api-reference/campaigns/get-campaign).
