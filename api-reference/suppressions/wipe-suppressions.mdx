---
title: "Delete All Suppressions via the API"
sidebarTitle: "Delete All Suppressions"
openapi: "/openapi.yaml DELETE /v2/accounts/{account_id}/suppressions/all"
description: "Clear every address from your AhaSend suppression list through one API call, optionally only for a single sending domain. This cannot be undone."
---


The AhaSend API deletes all suppressions for the account.

**Query Parameters:**
- `domain`: Optional domain filter to delete suppressions for specific domain only
