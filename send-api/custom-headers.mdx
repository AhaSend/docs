Use `headers` in a send request to add your own headers to the email, for example a reference ID your support team can search for, or a header your own systems read on replies.

Available on Free, Pro and Max. See [plans and features](/facts#plans-and-features).

<a id="add" />

## How Do I Add a Header?

`headers` is an object of header names and values. A `{{ variable }}` in a value is filled from the recipient's substitutions:

```json
{
  "sandbox": true,
  "from": { "email": "orders@yourdomain.com", "name": "Your Store" },
  "recipients": [
    { "email": "customer@example.com", "substitutions": { "order_id": "1001" } }
  ],
  "subject": "Order {{ order_id }} confirmed",
  "text_content": "Thanks for your order.",
  "headers": {
    "X-Order-ID": "{{ order_id }}",
    "X-Entity-Ref-ID": "order-{{ order_id }}"
  }
}
```

<a id="rules" />

## Which Rules Apply to Header Names and Values?

- A name must be visible ASCII, with no space and no colon. An empty name, or one with a space, a colon or a line break, is rejected.
- A substitution value used in a header must not contain a line break; the request is rejected and the error names the recipient.
- Header values are inserted as they are, without HTML escaping.

<a id="reserved" />

## Which Headers Does AhaSend Set for Me?

| Header | What happens |
| --- | --- |
| `Message-ID` | Always generated by AhaSend; a value in `headers` is ignored. The send response returns it as `message_id_header`. |
| `Reply-To` | Use the `reply_to` field. If you set `reply_to`, don't also put `Reply-To` in `headers`. |
| `To` | Set from `recipients`: one recipient per message. For several visible recipients, CC or BCC, use [Create Conversation Message](/send-api/multiple-recipients#cc-and-bcc). |
| `DKIM-Signature` | Added when the message is signed with your domain's key. |

<Note>
  Tracking, tags, retention and sandbox mode have their own fields in the API: see [Tags](/send-api/tags) and [Tracking and retention per message](/send-api/tracking-and-retention). Over SMTP, the same settings use [special headers](/smtp/special-headers).
</Note>
