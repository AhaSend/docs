AhaSend CLI `domains` commands let you add and verify sending domains; this page covers their arguments and flags.

Before running the examples, [log in with a full API key](/cli/authentication), use your verified sender domain, and replace `YOUR_RESOURCE_ID` with a resource UUID from your test account. Create any named template, recipient, attachment, or JSON files first. Shell examples use Bash; examples that read JSON with `jq` need jq installed. Sends use sandbox mode.

## Overview

```text
ahasend domains [subcommand] [flags]
```

Available subcommands:
- `list` - List all domains
- `create` - Add a new domain
- `get` - Get domain details
- `verify` - Verify domain DNS configuration
- `check-dns` - Check published DNS records
- `edit` - Update domain settings
- `delete` - Remove a domain

## List Domains

List all domains in your AhaSend account with their verification status, DNS record status, and other details. The list can be filtered and paginated for large numbers of domains.

```bash
# List all domains
ahasend domains list

# List domains with JSON output
ahasend domains list --output json

# List domains with pagination
ahasend domains list --limit 10

# Filter by DNS status
ahasend domains list --status verified
```


## Create Domain

```bash
ahasend domains create example.com
```

The command prints the exact SPF, DKIM, and DMARC records for your domain. Copy those values; see [domain setup](/domains).

## Verify Domain

After configuring DNS records:

```bash
ahasend domains verify example.com
```

<Note>
Most records verify within minutes. DNS changes can take up to 48 hours to propagate.
</Note>

## Get Domain Details

```bash
ahasend domains get example.com
```

## Check and Edit DNS Settings

```bash
ahasend domains check-dns yourdomain.com --verbose
ahasend domains edit yourdomain.com --tracking-subdomain track
```

Tracking and other service subdomains lock after DNS verification. To export records while adding a new test subdomain:

```bash
ahasend domains create docs-test.yourdomain.com --format terraform
```

`--format` also accepts `bind` and `cloudflare`; `--no-dns-help` omits DNS help.

## Delete Domain

```bash
# Delete with confirmation
ahasend domains create docs-delete-test.yourdomain.com
ahasend domains delete docs-delete-test.yourdomain.com

# Skip confirmation
ahasend domains create docs-delete-test.yourdomain.com
ahasend domains delete docs-delete-test.yourdomain.com --force
```

<Warning>
Deleting a domain is irreversible. You'll need to re-add and re-verify the domain if you want to use it again.
</Warning>

## Common DNS Setup

### Existing SPF Records

If you already have SPF records, merge them:

```text
# Before
v=spf1 include:_spf.google.com ~all

# After
v=spf1 include:_spf.google.com include:spf.ahasend.com ~all
```

### Subdomains

You can add subdomains for sending:

```bash
ahasend domains create mail.example.com
```

## Command Flags

These flags come from the current CLI. All commands also accept the [global flags](/cli/configuration#global-flags).

### `domains check-dns`

| Flag | Description and default |
|---|---|
| `--verbose` | Show detailed DNS information |

### `domains create`

| Flag | Description and default |
|---|---|
| `--format string` | DNS record format (bind, cloudflare, terraform) |
| `--no-dns-help` | Skip DNS configuration instructions |

### `domains delete`

| Flag | Description and default |
|---|---|
| `--force` | Skip confirmation prompt (use with caution) |

### `domains edit`

| Flag | Description and default |
|---|---|
| `--dkim-rotation-interval int` | DKIM rotation interval in days (managed DNS only, 30-180) |
| `--media-subdomain string` | Custom media subdomain |
| `--return-path-subdomain string` | Custom return-path subdomain |
| `--subscription-subdomain string` | Custom subscription management subdomain |
| `--tracking-subdomain string` | Custom tracking subdomain |

### `domains get`

This command has no command-specific flags. See [global flags](/cli/configuration#global-flags).

### `domains list`

| Flag | Description and default |
|---|---|
| `--cursor string` | Pagination cursor for next page |
| `--limit int32` | Maximum number of domains to return |
| `--status string` | Filter by DNS status (verified, pending, failed) |

### `domains verify`

| Flag | Description and default |
|---|---|
| `--verbose` | Show detailed DNS information |
