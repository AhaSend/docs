Manage email suppressions (bounces, complaints, unsubscribes).

Before running the examples, [log in with a full API key](/cli/authentication), use your verified sender domain, and replace `YOUR_RESOURCE_ID` with a resource UUID from your test account. Create any named template, recipient, attachment, or JSON files first. Shell examples use Bash; examples that read JSON with `jq` need jq installed. Sends use sandbox mode.

## Overview

```text
ahasend suppressions [subcommand] [flags]
```

Available subcommands:
- `list` - List all suppressed email addresses
- `create` - Create a new suppression for an email address
- `check` - Check if an email address is suppressed
- `delete` - Delete an email address from the suppression list
- `wipe` - Delete all suppressions from your account

Suppressions are email addresses that should not receive emails from your account. They can be created automatically (bounces, complaints) or manually (unsubscribes).

Use suppressions to:
- View all suppressed email addresses
- Check if a specific email is suppressed
- Create new suppressions for email addresses
- Delete existing suppressions
- Bulk manage suppressions

## List Suppressions

List suppressed email addresses with filtering and pagination support. Suppressions are email addresses that should not receive emails from your account. They can be filtered by email address, domain, creation time, and exported to JSON format.

```bash
# List all suppressions
ahasend suppressions list

# Search for specific email suppression
ahasend suppressions list --email user@example.com

# Filter by domain
ahasend suppressions list --domain example.com

# Export to JSON
ahasend suppressions list --output json

# List with pagination
ahasend suppressions list --limit 100
```


## Create Suppression

```bash
# Create manual suppression
ahasend suppressions create user@example.com --reason unsubscribe --expires 30d

# Create bounce suppression
ahasend suppressions create user@example.com --reason "Manual bounce test" --expires 30d

# Create complaint suppression
ahasend suppressions create user@example.com --reason "Manual complaint test" --expires 30d
```

## Check Suppression

```bash
ahasend suppressions check user@example.com
```

## Delete Suppression

```bash
ahasend suppressions create docs-delete-test@example.com --reason "Docs deletion test" --expires 1d
ahasend suppressions delete docs-delete-test@example.com
```

## Wipe Suppressions

Remove all suppressions (use with caution):

```bash
# Wipe all suppressions
ahasend suppressions create docs-wipe-test@example.com --domain docs-test.example.com --reason "Docs wipe test" --expires 1d
ahasend suppressions wipe --force --domain "docs-test.example.com"

# Wipe specific type
ahasend suppressions create docs-wipe-test@example.com --domain docs-test.example.com --reason "Docs wipe test" --expires 1d
ahasend suppressions wipe --domain "docs-test.example.com" --force
```

<Warning>
This action is irreversible and will remove all specified suppressions.
</Warning>

## Command Flags

These flags come from the current CLI. All commands also accept the [global flags](/cli/configuration#global-flags).

### `suppressions check`

| Flag | Description and default |
|---|---|
| `--domain string` | Check suppression for specific domain only |

### `suppressions create`

| Flag | Description and default |
|---|---|
| `--domain string` | Domain for domain-specific suppression (optional) |
| `--expires string` | Expiration time (e.g., '30d', '`RFC3339_TIMESTAMP`') [required] |
| `--reason string` | Suppression reason (up to 255 characters) |

### `suppressions delete`

| Flag | Description and default |
|---|---|
| `--domain string` | Domain for domain-specific suppression removal (optional) |
| `--force` | Skip confirmation prompt |

### `suppressions list`

| Flag | Description and default |
|---|---|
| `--cursor string` | Pagination cursor for continued results |
| `--domain string` | Filter by specific domain |
| `--email string` | Email address to search for (optional) |
| `--limit int32` | Maximum number of suppressions to return (default 50) |

### `suppressions wipe`

| Flag | Description and default |
|---|---|
| `--domain string` | Domain to wipe suppressions for |
| `--force` | Skip all confirmation prompts (DANGEROUS) |
