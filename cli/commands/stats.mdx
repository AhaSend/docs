AhaSend CLI `stats` commands report delivery, bounce and delivery-time statistics; this page covers filters and output.

Before running the examples, [log in with a full API key](/cli/authentication), use your verified sender domain, and replace `YOUR_RESOURCE_ID` with a resource UUID from your test account. Create any named template, recipient, attachment, or JSON files first. Shell examples use Bash; examples that read JSON with `jq` need jq installed. Sends use sandbox mode.

## Overview

```text
ahasend stats [subcommand] [flags]
```

Available subcommands:
- `deliverability` - View delivery statistics
- `bounces` - Analyze bounce rates
- `delivery-time` - Check delivery performance

## Deliverability Statistics

```bash
# Basic deliverability stats (last 7 days)
ahasend stats deliverability

# Custom date range
ahasend stats deliverability \
  --from-time 7d \
  --to-time 0h

# Group by time period
ahasend stats deliverability \
  --group-by day \
  --from-time 7d
```

### Grouping Options

- `hour` - Hourly breakdown
- `day` - Daily breakdown (default)
- `week` - Weekly breakdown
- `month` - Monthly breakdown

### Export to CSV

```bash
ahasend stats deliverability \
  --from-time 7d \
  --to-time 0h \
  --output csv > deliverability-report.csv
```

## Bounce Analysis

```bash
# Basic bounce report
ahasend stats bounces

# Detailed bounce analysis
ahasend stats bounces \
  --from-time 7d \
  --to-time 0h \
  --group-by day
```

### Bounce Categories

Use `--classification` for the server's classification breakdown and `--show-domains` to group affected recipient domains. See [bounce statistics](/api-reference/reports/get-bounce-report).

## Delivery Time Performance

```bash
# Basic delivery time stats
ahasend stats delivery-time

# Hourly breakdown
ahasend stats delivery-time \
  --group-by hour \
  --from-time 7d
```

## Advanced Options

### Campaign Performance

```bash
# Filter by tags
ahasend stats deliverability \
  --tags "campaign-summer-2024" \
  --from-time 7d \
  --to-time 0h
```

### Domain-Specific Stats

```bash
# Stats for specific domain
ahasend stats deliverability \
  --sender-domain example.com \
  --group-by day
```

## Command Flags

These flags come from the current CLI. All commands also accept the [global flags](/cli/configuration#global-flags).

### `stats bounces`

| Flag | Description and default |
|---|---|
| `--classification` | Show classification summary breakdown |
| `--from-time string` | Start time (RFC3339 format or relative like '7d', '24h') (default "7d") |
| `--group-by string` | Group results by: hour, day, week, month (default "day") |
| `--raw` | Show raw data without interpretation (useful for CSV/JSON) |
| `--recipient-domain strings` | Filter by recipient domains (can be used multiple times) |
| `--sender-domain string` | Filter by sender domain |
| `--show-domains` | Show top bouncing recipient domains |
| `--show-totals` | Show summary totals (default true) |
| `--tags string` | Filter by message tags (comma-separated) |
| `--to-time string` | End time (RFC3339 format or relative, defaults to now) |
| `--trends` | Show time-period focused trends (default) |

### `stats deliverability`

| Flag | Description and default |
|---|---|
| `--chart` | Show ASCII chart visualization |
| `--from-time string` | Start time (RFC3339 format or relative like '7d', '24h') (default "7d") |
| `--group-by string` | Group results by: hour, day, week, month (default "day") |
| `--raw` | Show raw data without interpretation (useful for CSV/JSON) |
| `--recipient-domain strings` | Filter by recipient domains (can be used multiple times) |
| `--sender-domain string` | Filter by sender domain |
| `--show-totals` | Show summary totals (default true) |
| `--tags string` | Filter by message tags (comma-separated) |
| `--to-time string` | End time (RFC3339 format or relative, defaults to now) |

### `stats delivery-time`
