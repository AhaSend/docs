[Echo](https://echo.labstack.com) hides the request behind `echo.Context`, so unwrap it: `c.Request()` for `verifier.ParseRequest`. The trap is middleware, since `BodyDump`, `BodyLimit`, or a global binder will consume the webhook body before verification.

## Prerequisites

- Go 1.18 or later
- An [AhaSend account](https://dash.ahasend.com/user/register) with a verified sending domain
- An [API key](https://dash.ahasend.com/account/-/settings/api-keys) with the `messages:send:all` scope, and your account ID

## Install the SDK

```bash
go get github.com/AhaSend/ahasend-go
go get github.com/labstack/echo/v4
```

## Configure Environment Variables

```bash
export AHASEND_API_KEY=aha-sk-...
export AHASEND_ACCOUNT_ID=your-account-uuid
export AHASEND_WEBHOOK_SECRET=aha-whsec-...
```

## Create the Client

Create the client once at startup and share it across handlers: it maintains its own rate-limit, retry, and idempotency state:

```go main.go
package main

import (
	"log"
	"os"

	"github.com/AhaSend/ahasend-go/api"
	"github.com/google/uuid"
	"github.com/labstack/echo/v4"
	"github.com/labstack/echo/v4/middleware"
)

var (
	ahasendClient *api.APIClient
	accountID     uuid.UUID
)

func main() {
	var err error
	accountID, err = uuid.Parse(os.Getenv("AHASEND_ACCOUNT_ID"))
	if err != nil {
		log.Fatalf("invalid AHASEND_ACCOUNT_ID: %v", err)
	}

	ahasendClient = api.NewAPIClient(api.WithAPIKey(os.Getenv("AHASEND_API_KEY")))

	e := echo.New()
	e.Use(middleware.Logger())
	e.POST("/api/welcome", sendWelcome)
	e.POST("/webhooks/ahasend", handleAhaSendWebhook)
	e.Logger.Fatal(e.Start(":8080"))
}
```

`middleware.Logger()` only logs request metadata, so it's safe on every route, including the webhook route.

## Send an Email from an Echo Handler

Echo handlers take an `echo.Context` and return an `error`. Bind the JSON body into a struct with `c.Bind`:

```go send.go
package main

import (
	"errors"
	"log"
	"net/http"

	"github.com/AhaSend/ahasend-go"
	"github.com/AhaSend/ahasend-go/api"
	"github.com/AhaSend/ahasend-go/models/common"
	"github.com/AhaSend/ahasend-go/models/requests"
	"github.com/labstack/echo/v4"
)

type welcomeInput struct {
	Email string `json:"email"`
	Name  string `json:"name"`
}

func sendWelcome(c echo.Context) error {
	var in welcomeInput
	if err := c.Bind(&in); err != nil {
		return echo.NewHTTPError(http.StatusBadRequest, "invalid JSON body")
	}
	if in.Email == "" {
		return echo.NewHTTPError(http.StatusBadRequest, "email is required")
	}

	message := requests.CreateMessageRequest{
		From:        common.SenderAddress{Email: "hello@yourdomain.com", Name: ahasend.String("Your App")},
		Recipients:  []common.Recipient{{Email: in.Email, Name: ahasend.String(in.Name)}},
		Subject:     "Welcome to Your App!",
		HtmlContent: ahasend.String("<h1>Welcome aboard 🎉</h1><p>We're glad you're here.</p>"),
		TextContent: ahasend.String("Welcome aboard! We're glad you're here."),
	}

	response, _, err := ahasendClient.MessagesAPI.CreateMessage(c.Request().Context(), accountID, message)
	if err != nil {
		var apiErr *api.APIError
		if errors.As(err, &apiErr) {
			log.Printf("AhaSend error %d: %s", apiErr.StatusCode, string(apiErr.Raw))
			return echo.NewHTTPError(http.StatusBadGateway, "failed to send email")
		}
		return echo.NewHTTPError(http.StatusInternalServerError, "unexpected error")
	}

	messageID := ""
	if len(response.Data) > 0 && response.Data[0].ID != nil {
		messageID = *response.Data[0].ID
	}
	return c.JSON(http.StatusOK, map[string]string{"message_id": messageID})
}
```

The SDK automatically retries rate-limited requests with exponential backoff and attaches an idempotency key to every send. Stored outcomes replay for 24 hours, but a 5xx is not stored, so a retry after a server error can still send twice.

## Handle Webhooks

Echo exposes the underlying `*http.Request` via `c.Request()`, so the SDK's `ParseRequest` works directly: it verifies the HMAC signature, guards against replays, and returns a typed event.

<Warning>
  `ParseRequest` consumes the request body and must see it untouched. Don't run body-reading middleware (`middleware.BodyDump`, `middleware.BodyLimit`, custom binders) ahead of this route, and don't call `c.Bind` on it yourself.
</Warning>

```go webhook.go
package main

import (
	"errors"
	"log"
	"net/http"
	"os"

	"github.com/AhaSend/ahasend-go/webhooks"
	"github.com/labstack/echo/v4"
)

var verifier *webhooks.WebhookVerifier

func init() {
	var err error
	verifier, err = webhooks.NewWebhookVerifier(os.Getenv("AHASEND_WEBHOOK_SECRET"))
	if err != nil {
		log.Fatalf("failed to create webhook verifier: %v", err)
	}
}

func handleAhaSendWebhook(c echo.Context) error {
	event, err := verifier.ParseRequest(c.Request())
	if err != nil {
		switch {
		case errors.Is(err, webhooks.ErrMissingHeaders),
			errors.Is(err, webhooks.ErrInvalidSignature),
			errors.Is(err, webhooks.ErrExpiredTimestamp):
			return c.NoContent(http.StatusUnauthorized)
		default:
			return c.NoContent(http.StatusBadRequest)
		}
	}

	switch e := event.(type) {
	case *webhooks.MessageDeliveredEvent:
		log.Printf("delivered to %s", e.Data.Recipient)
	case *webhooks.MessageBouncedEvent:
		log.Printf("bounced: %s", e.Data.Recipient)
	case *webhooks.MessageOpenedEvent:
		log.Printf("opened by %s", e.Data.Recipient)
	default:
		log.Printf("unhandled event type: %s", event.GetType())
	}

	return c.NoContent(http.StatusOK)
}
```

Create the webhook in your [AhaSend dashboard](https://dash.ahasend.com) pointing at `https://your-app.com/webhooks/ahasend`, and copy its secret into `AHASEND_WEBHOOK_SECRET` exactly as shown (including the `aha-whsec-` prefix).

Return 200 promptly and do slow processing in a goroutine or queue, because AhaSend retries webhooks that don't get a timely 2xx.

## Going Further

- **Templating**: set `Substitutions: map[string]interface{}{"first_name": "Jane"}` and use `{{ first_name }}` in the subject or body.
- **Batch sends**: `Recipients` accepts up to 100 entries; each gets a separate message.
- **Tags**: set `Tags: []string{"welcome"}` to filter messages in lists, statistics, and webhooks.
- **Rate limits**: sending at volume? Tune the client with `ahasendClient.SetSendMessageRateLimit(500, 1000)`.
- **Other frameworks**: the same SDK patterns work in [Gin](/guides/gin), [Fiber](/guides/fiber), and [chi](/guides/chi).
- **Attachments**: add `Attachments` with `Data`, `ContentType`, and `FileName`. Set `Base64: true` for binary files such as PDFs.

See the [API reference](https://ahasend.com/docs/api-reference) for every service the SDK exposes (`DomainsAPI`, `SuppressionsAPI`, `StatisticsAPI`, and more).

## Troubleshooting

<AccordionGroup>
  <Accordion title="401 from the API">
    The API key is missing, malformed, or revoked. Verify `AHASEND_API_KEY` is set in the process environment and that the key exists in your [dashboard](https://dash.ahasend.com/account/-/settings/api-keys).
  </Accordion>
  <Accordion title="Webhook verification always fails">
    Something consumed the request body before `ParseRequest` ran: `middleware.BodyDump`, `middleware.BodyLimit`, or a custom binder registered globally will all do this. Move them off the webhook route. Also confirm the secret matches the dashboard exactly, including the `aha-whsec-` prefix.
  </Accordion>
  <Accordion title="c.Bind leaves my struct empty">
    Echo binds by `Content-Type`. Make sure the client sends `Content-Type: application/json`; without it, `c.Bind` won't decode the JSON body and your struct fields stay zero-valued.
  </Accordion>
  <Accordion title="400 error mentioning the from address">
    The `From` address must belong to a verified sending domain on your account. Check domain status in the dashboard.
  </Accordion>
</AccordionGroup>
